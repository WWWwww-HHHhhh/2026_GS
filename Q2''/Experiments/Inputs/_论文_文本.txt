[P0] 问题二:考虑实际负荷与光伏波动的微网购电与储能调度策略
[P1] 模型概述
[P2] 先用季节朴素、岭回归与梯度提升树按 WAPE 最小逐日预测负荷和光伏，其残差经整日块自助抽样生成场景。为刻画预测偏差带来的成本风险，建立带 CVaR 的两阶段随机线性规划，得到共享计划购电与储能方案，最后由结算模型按真实数据确定紧急购电与费用。软终端系数 κ2 经储能边际价值校准，用于维持跨日电量平衡。

[P4] 三、模型建立
[P5] 3.1 数据准备与软终端系数校准
[P6] 数据直接复用第 6 章全局预处理与转换的产物：附件 1 提供固定日内电价 πt（144 个时段，全年复用）；附件 2 的负荷与光伏已由功率换算为时段电量，单位为 kWh。负荷电量范围为 [332.620, 1329.814] kWh，光伏电量范围为 [0, 1702.700] kWh，电价范围为 [0.3713, 1.3952] 元/kWh。
[P7] 储能设备参数为：电量下界 Smin = 1200 kWh，电量上界 Smax = 10800 kWh，初始电量 S0 = 6000 kWh；充、放电效率 ηc = ηd = 0.9；充、放电功率上限均为 500 kW，对应单时段电量上限 C̄ = R̄ = 833.333 kWh。附件 2 的功率 P_t（kW）按 10 min 时长换算为时段电量 E_t = P_t/6（kWh）。
[P8] 本文全篇时间标签采用真实时段口径：标签“12:00—12:10”表示真实时段 12:00—12:10（即附件中时间标签为 12:10 的行/列）。官方结果模板的列名存在循环排列，result2.xlsx 按真实时段填入：第 2～144 列依次为本日真实时段 0:10—0:20 至 23:50—24:00，末列“0:00—0:10+1”为次日 0:00—0:10；2025-02-01 的首个时段（0:00—0:10）并入当日充放电量 0:00—4:00 合计，2025-12-31 行末列留空（对应 2026-01-01，超出附件数据范围）。
[P9] 设附件时间标签为 k = 1, 2, …, 144，其对应真实时段为 (10(k−1), 10k] 分钟。时间标签采用向上取整到时段末端：标签 10k 分钟归入 (10(k−1), 10k]，因此 12:10 对应 12:00—12:10，而非 11:50—12:00。
[P10] 储能软终端系数 κ2 用于惩罚当日末电量偏离期初电量，以抑制储能电量的长期漂移。取问题一导出的储能边际价值序列的中位数作为基准：κ2,base = 0.531667（样本量 144），并经调参最终取 κ2 = 0.132917。该中位数仅作为调参基准，不是理论最优值；理论上软终端惩罚应采用当日末端储能的边际价值，即问题一对偶问题中 SOC 状态方程的影子价格。本文以该边际价值序列的中位数 κ2,base = 0.531667 作为基准，再乘以 0.25 倍，最终由 4.5 节滚动调参确定 κ2 = 0.132917 元/kWh。
[P11] 3.2 因果预测模型
[P12] 对负荷与光伏分别建立预测模型，特征包括：时段序号 t、星期、年内日序、前 1 天同时刻实际值、前 7 天同时刻实际值及其 7 天滚动均值、滚动标准差。候选模型为季节朴素、Ridge 回归与梯度提升树 GBM；逐日以前一日作为验证集，选择加权绝对百分比误差 WAPE 最小者作为当日预测模型。
[P13] 对第 i 天第 t 时段，特征向量为 x_{i,t} = [t, 星期 d_{i,t}, 年内日序 n_i, y_{i−1,t}, y_{i−7,t}, μ_{i,t}^{(7)}, σ_{i,t}^{(7)}]^T，其中 μ_{i,t}^{(7)}、σ_{i,t}^{(7)} 分别为该时刻前 7 天实际值的均值与标准差。负荷与光伏分别用各自历史序列 y ∈ {L, G} 构造上述特征。
[P14] 季节朴素：  ŷi,t = medianj<i yj,t
[P15] Ridge：  min_w ‖y − Xw‖₂² + λ‖w‖₂²,  λ = 1.0
[P16] WAPE = Σt|ŷi,t − yi,t| / Σt|yi,t|
[P17] 梯度提升树：F_m(x) = F_{m−1}(x) + ν h_m(x)，其中 h_m 为拟合残差 r_m = y − F_{m−1}(x) 的回归树，学习率 ν = 0.1；超参数为最大迭代 100、最大深度 3、叶节点最小样本 20。
[P18] 模型选择规则：对决策日 i，训练样本仅取 i 之前的历史，验证集取第 i−1 日；记候选模型 m ∈ {季节朴素, Ridge, GBM}，选择 m̂_i = arg min_m WAPE_{i−1}^{(m)}，再用 m̂_i 预测第 i 日，实现逐日滚动切换。
[P19] 3.3 经验场景生成
[P20] 定义负荷、光伏的预测残差 εLj,t = Lj,t − L̂j,t，εGj,t = Gj,t − Ĝj,t。以整日为块，仅对决策日之前的历史残差进行同日成对的自助抽样，将残差块叠加到当日预测上并截断非负，生成场景：
[P21] Lωi,t = max(0, L̂i,t + εLb,t),   Gωi,t = max(0, Ĝi,t + εGb,t)
[P22] 最终场景数取 M = 20，随机种子为 20260101；负荷与光伏残差同日成对抽取，保证二者相关性不被破坏。
[P23] 残差按整日块归档为 B = {(ε_{b,t}^L, ε_{b,t}^G) : b < i}。每个场景 ω 等概率 p_ω = 1/M，独立有放回地从 B 抽取整日块 b_ω，将负荷残差与光伏残差成对叠加到当日点预测上，生成场景矩阵 L, G ∈ R^{365×M×144}。
[P24] 3.4 两阶段随机线性规划模型
[P25] 第一阶段变量 x, c, r, s, ξ+, ξ- 跨场景共享，体现 0:00 决策的非预期性；第二阶段变量 y, e, g, w, u, q 按场景独立。场景 ω 的成本为
[P26] 其中 x 是 0:00 签订并按量付费的计划购电量，当日确定后不能修改；c、r 是 0:00 制定的计划充、放电上限，不是对未来实际动作的预测值，同样跨场景共享。实际充放电只能在 [0, c] 与 [0, r] 内调整，因此第一阶段不包含任何场景私有信息，避免未来信息泄漏。
[P27] 变量边界：x_{i,t} ≥ 0，0 ≤ c_{i,t} ≤ 833.333，0 ≤ r_{i,t} ≤ 833.333，1200 ≤ s_{i,t} ≤ 10800，ξ_i^+、ξ_i^- ≥ 0；0 ≤ y_{i,t}^ω ≤ x_{i,t}，e_{i,t}^ω ≥ 0，0 ≤ g_{i,t}^ω ≤ G_{i,t}^ω，w_{i,t}^ω ≥ 0，u_{i,t}^ω ≥ 0，q_ω ≥ 0，ζ ∈ R。上述约束对 t = 1, …, 144、ω = 1, …, M 成立。
[P28] 跨日初值满足 s_{i,0} = s_{i−1,T}^{actual}；2025-02-01 的期初电量等于 2025-01-31 结算后的实际期末电量，不每日重置。
[P29] Cωi = Σt πt xi,t + 5 Σt πt eωi,t
[P30] 引入 CVaR 刻画最坏 10% 场景的平均成本（α = 0.90）：
[P31] qω ≥ Cωi − ζ,   qω ≥ 0;   CVaR = ζ + 1/((1−α)M) Σω qω
[P32] 目标函数为
[P33] min Ji = (1−β)(1/M)Σω Cωi + β CVaR + ε Σt(ci,t+ri,t) + κ2(ξ++ξ-)
[P34] 其中风险权重 β 用于权衡期望成本与最坏 10% 场景的平均成本：β 越大计划越保守。β 的取值不能凭经验指定，本文在 4.5 节以“费用增幅预算内紧急购电率最低”的准则由真实调参数据确定，最终取 β = 0.25。
[P35] 约束条件包括电量平衡、未提取量、弃光量、储能电量递推、软终端以及各类边界：
[P36] yωt + eωt + gωt + rt = Lωt + ct
[P37] xt − yωt − uωt = 0,   gωt + wωt = Gωt
[P38] st − st−1 − ηc ct + rt/ηr = 0,   sT − sref = ξ+ − ξ-,  sref = s0
[P39] 0 ≤ yωt ≤ xt,  0 ≤ ct ≤ 833.333,  0 ≤ rt ≤ 833.333,  1200 ≤ st ≤ 10800,  0 ≤ gωt ≤ Gωt
[P40] 除上式外还需满足非负性：e_{i,t}^ω ≥ 0，w_{i,t}^ω ≥ 0，u_{i,t}^ω ≥ 0，q_ω ≥ 0，ξ_i^+、ξ_i^- ≥ 0。
[P41] 题目未要求计划购电量必须全部提取，故采用 0 ≤ y_{i,t}^ω ≤ x_{i,t}。作为题意敏感性，若增加全量提取约束 y_{i,t}^ω = x_{i,t}，则调参窗口内模型不可行，说明允许少提计划量是维持可行性的必要条件。
[P42] 其中 ε 为求解用小量惩罚，κ2 为软终端惩罚，二者只用于求解，不计入报告费用。
[P43] 3.5 事后结算模型
[P44] 当日真实负荷与光伏实现后，固定 0:00 计划 x, c, r，重新求解实际运行：实际提取 0 ≤ y ≤ x，实际充放电 0 ≤ cactual ≤ c、0 ≤ ractual ≤ r，电量平衡 y + e + g + ractual = L + cactual，储能递推使用实际充放电量。结算目标为
[P45] 结算阶段变量为实际提取 y_t、紧急购电 e_t、光伏消纳 g_t、弃光 w_t、实际充放电 c_t^{a}、r_t^{a} 与实际电量 s_t^{a}。约束为 0 ≤ y_t ≤ x_t，0 ≤ c_t^{a} ≤ c_t，0 ≤ r_t^{a} ≤ r_t，y_t + e_t + g_t + r_t^{a} = L_t + c_t^{a}，g_t + w_t = G_t，0 ≤ g_t ≤ G_t，w_t ≥ 0，s_t^{a} = s_{t−1}^{a} + η_c c_t^{a} − r_t^{a}/η_r，1200 ≤ s_t^{a} ≤ 10800。
[P46] 当日实际期末电量 s_T^{a} 作为次日优化与结算的期初值 s_{next,0}，实现跨日滚动闭环；结算中的 c、r 均为计划上限，实际执行以 [0, c]、[0, r] 为可行域。
[P47] min 5 Σt πt et − Mplan Σt(cactual,t + ractual,t),  Mplan = 20
[P48] 其中 Mplan 仅用于在可行范围内优先执行计划，不计入报告费用。报告费用为：计划购电费 costplan = Σtπtxt，紧急购电费 costemergency = 5Σtπtet，总费用为二者之和。
[P49] 上述结算目标与 min 5Σtπtet + MplanΣt[(ct − cactual,t) + (rt − ractual,t)] 仅相差常数 MplanΣt(ct + rt)，故 Mplan 项在代数上等价于“优先执行计划”的偏差惩罚，且不计入报告费用。
[P50] 为让该等价性形成逻辑闭环，还需验证结算最优解中的执行偏差只可能由物理约束引起，不会被费用权衡利用。附件 1 全年最高电价为 1.3952 元/kWh，5 倍紧急电价上限为 6.976 元/kWh，小于 Mplan = 20 元/kWh；任意“少执行 1 kWh 计划充放电以换取少 1 kWh 紧急购电”的操作最多节省 6.976 元，却损失 20 元执行奖励，净亏，故最优解不会为节省费用而主动偏离计划。
[P51] 对 334 个报告日逐时段复核：放电偏差合计 12,547.56 kWh，全部出现在 ractual,t 恰等于 Lt + cactual,t 的时段，即计划放电量超过当日实际负荷可吸收量（实际负荷低于 20 个残差场景包络）的强制削减；充电偏差合计 5,469.27 kWh，全部集中在 SOC 触及 10800 kWh 上界的 14 个日期，属于“当日某时段多充、后续必须等量少放”的零和置换（退化最优解），两类偏差均不改变报告费用口径。全年 SOC 越界天数为 0、跨日 SOC 结转偏差为 0、结算平衡残差最大值 3.411×10−13，表明 F1 的等价性在代数层、经济层与数据层三处闭环成立。
[P52] 3.6 求解与滚动闭环
[P53] 每日 0:00 前依次执行 3.2 因果预测、3.3 场景生成与 3.4 两阶段随机规划，得到共享计划 x、c、r；当日真实 L、G 实现后执行 3.5 结算，并把实际期末 SOC 与当日残差块送入次日，形成“预测—场景—计划—结算—更新”的扩展窗口滚动回测。2025 年 1 月为预热期，2—12 月为正式报告期。
[P54] 四、模型求解
[P55] 求解整体按因果预测、经验场景生成、两阶段随机线性规划、事后结算的顺序滚动推进。线性规划统一调用 scipy.optimize.linprog 内置的 HiGHS 求解器，并以 scipy.sparse.coo_matrix 稀疏矩阵装配约束，保证 M 个场景叠加后的大规模问题的求解效率与数值稳定性。
[P56] 4.1 因果预测求解
[P57] 对负荷与光伏分别按 3.2 节的特征与候选模型逐日求解，其中 Ridge 取 λ = 1.0，GBM 取最大迭代 100 次、最大深度 3、学习率 0.1、叶节点最小样本 20。训练集严格截止到决策日前一天，以前一日作为验证集计算 WAPE，选择 WAPE 最小的模型对次日执行预测，实现模型随误差反馈动态切换。预测结果以点预测和逐日残差两种形式分别送入场景生成与残差库更新环节。
[P58] 4.2 经验场景生成求解
[P59] 逐日计算负荷与光伏残差并按整日块成对归档，残差库仅保留决策日之前的样本，保证场景生成不泄漏未来信息。以随机种子 20260101 对残差日块执行 M = 20 次联合自助抽样，将抽样块叠加到当日点预测并对负值截断为 0，生成规模为 (365, 20, 144) 的场景矩阵。截断后光伏场景零值占比 30.84%，负荷场景零值占比 0.38%，表明截断主要作用于光伏为零的夜间时段。
[P60] 4.3 两阶段随机线性规划求解
[P61] 单日规划将第一阶段变量 x, c, r, s, ξ± 跨场景共享，第二阶段变量 y, e, g, w, u, q 按场景独立装配。目标函数按 (1 − β) 期望成本与 β CVaR 加权，CVaR 由分位数变量 ζ 与辅助变量 q 的线性约束等价表示，ε = 10⁻⁴ 仅用于抑制无谓充放电，κ2 软终端惩罚维持跨日电量平衡，充放电效率取 ηc = ηr = 0.9。求解时逐场景装配电量平衡、未提取、弃光与 SOC 递推约束并调用 HiGHS，返回各场景最优解后提取第一阶段共享计划。M = 20 时单日变量规模约 14,999 个，规划平衡残差最大值 1.137×10⁻¹³，SOC 越界数为 0，第一阶段变量跨场景共享成立，验证了约束装配与求解的正确性。
[P62] 4.4 事后结算模型求解
[P63] 0:00 计划 x, c, r 一经确定不再调整，当日真实负荷与光伏实现后，以实际提取 y、紧急购电 e、光伏消纳 g、实际充放电 cactual 与 ractual、实际储能电量 sactual 为变量重解结算 LP，约束为 3.5 节定义的计划可行域、电量平衡与 SOC 递推。结算目标为 min 5Σtπtet − MplanΣt(cactual,t + ractual,t)，Mplan = 20 仅用于在可行范围内优先执行计划，不计入报告费用。按 costplan 与 costemergency 复算当日费用，结算平衡残差最大值 3.411×10⁻¹³，验证了结算求解的数值可靠性。
[P64] 4.5 滚动流程与超参数选择
[P65] 滚动求解顺序为，2025-01-01 保持 SOC = 6000 kWh 不优化，2025 年 1 月整月为预热期只积累预测残差，报告期为 2025-02-01 至 2025-12-31 共 334 天，调参窗口为 2025-02-01 至 02-28 共 28 天。对 β ∈ {0, 0.25, 0.5, 0.75, 1.0}、M ∈ {10, 20, 30}、κ2 倍数 ∈ {0.25, 0.5, 1.0, 2.0} 做网格搜索。β 的选择不能只按费用最小（那会退回 β = 0，紧急购电率高达 0.6826%），而是采用“费用增幅预算内紧急购电率最低”的准则：β = 0.25 时费用较 β = 0 仅增加 6.01%（1,360,933.08 → 1,442,790.32 元），紧急购电率由 0.6826% 降至 0.4163%（下降 39.0%）；继续增大到 β = 0.5，费用较 β = 0.25 再增 20.0%，紧急购电率仅再降 20.3%，边际性价比明显下降。故取 β = 0.25；固定 β = 0.25 后，M = 20 时调参窗口总费用最低，κ2 取 0.25 倍基准（0.132917 元/kWh），最终参数为 β = 0.25、M = 20、κ2 = 0.132917、α = 0.90。
