# Q4_wyh 目录规则与协作约定

> 适用范围：本工作区的一切产出。不遵守落点规则的产物视为临时件，不进入论文与提交材料。

## 1. 工作根与目录契约

```
Q4/Q4_wyh/
├── Data_processing/                 # 只做"数据 → 可求解输入"：读取、对齐、预测、场景生成
│   ├── forecast/                    # 因果预测器（价格/负荷/光伏）
│   └── scenarios/                   # 联合场景抽样与诊断
├── Model_Establishment+Solution/    # 只做"模型 → 解"：模型定义、求解器、结算、导出
├── Results/
│   ├── Pictures/                    # 所有图（PDF 投稿 + PNG 预览），图脚本也放这里
│   └── Tables/                      # 所有表（csv/xlsx/tex）与验证报告
└── others/                          # 其余一切：原始附件、提示词、规则、思路、临时核验脚本
    ├── 原始附件_CUMCM2026_C/        # 官方题目与附件（只读，禁止改写）
    └── _intake_check/               # 入场核验脚本与日志
```

**落点判定三问**：这段代码是"造输入"还是"用输入求解"？→ 分别进 `Data_processing` / `Model_Establishment+Solution`；
产物是图还是表？→ `Results/Pictures` / `Results/Tables`；都不是（提示词、规则、草稿、临时验证）→ `others`。

## 2. 数据基准（唯一口径，禁止另起一套）

内部标准格式 = `All_Code/Data_preprocessing/Data_transformation/*.parquet`，Q4 直接读，不再重新清洗原始 xlsx：

| 文件 | 形状 | 含义 |
| --- | --- | --- |
| `df_load.parquet` | 365 × (1+144) | `date` + `T001..T144`，**kWh/时段**（原始 kW × 1/6） |
| `df_pv.parquet` | 365 × (1+144) | 同上，光伏实际发电量 |
| `df_price.parquet` | 365 × (1+144) | 电价，**元/kWh**（不换算） |
| `df_fcst.parquet` | 1460 × 26 | `date, issue_hour∈{0,6,12,18}, fh_01..fh_24`，**kW**，小时级，不插值 |
| `df_p1.parquet` | 144 × 5 | 附件1 典型日：`price / load_kwh / pv_kwh` |
| `time_map.csv` | 144 × 7 | 内部 `T001..T144` ↔ 附件标签 ↔ 模板行列标签 |
| `template_map.csv` | 1092 × 12 | result1~result4-3 各 sheet 字段的写入位置 |

时间定义：`T_t = ((t-1)·10min, t·10min]`，`T144 = (23:50, 24:00]`，即"时段结束时刻"标签。

## 3. 禁止事项

1. **禁止改写** `Data/附件/`、`Q4/Q4_wyh/others/原始附件_CUMCM2026_C/`、`All_Code/` 下任何已有文件（Q1–Q3 与共享预处理已定稿，路径被硬编码引用）。
2. **禁止** 在 `Results/` 里放脚本，**禁止** 在 `Data_processing/` 里堆结果表。
3. **禁止** 让论文数值脱离 `Results/Tables` 与模板工作簿：数字必须能由脚本重跑复现。
4. **禁止** 使用决策时刻未知的信息（当天未来时段的实际值）；结算时才允许读当天实际值。
5. **禁止** 把占位符、示例值、手改结果写进任何表或图。

## 4. 每次产出的最小血缘

`输入文件（含路径+sha256） → 脚本（含命令行、随机种子、包版本） → 输出文件`，写入对应阶段的 `*_report.md` 或 `run_metadata.json`。

## 5. 命名约定

- 脚本：`NN_作用.py`（如 `03_q4_data_prepare.py`、`q4_2_solve.py`），可复现命令写在文件头 docstring。
- 结果表：`q4_2_*.csv` / `q4_3_*.csv`；图：`fig_q4_*.pdf|png`。
- 报告：`RESULTS_REPORT.md`、`validation_report.txt`。
