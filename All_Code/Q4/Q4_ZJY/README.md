# Q4-3 代码说明：波动电价下的滚动购电优化

问题四（优化部分）：用**附件 4 的每日波动电价**替换附件 1 的固定电价，重算问题三（多时点光伏预报驱动的滚动购电优化），产出 `result4-3.xlsx`。

## 关键建模决策：电价信息假设

附件 4 为 2025 全年每天 144 个 10 分钟时段的**实际电价**。题面只说明电价“实时波动”，没有说明每天 0:00 已发布未来 144 个价格。因此，主模型在每个决策时点只使用因果日前价格预测和严格早于目标日的历史残差块，构造价格、负荷和光伏的联合场景。目标日实价只用于已执行时段的结算，及其后作为历史数据进入预测误差库。

## 与 Q3 的复用关系（核心思路）

Q4-3 复用 Q3 的储能物理约束、光伏更新机制、执行结算和导出链，但将确定价格层替换为因果联合价格场景层：

| 组件 | 来源 | 说明 |
|---|---|---|
| **电价** | **附件 4 与 Q4-2 预测器（新）** | 当日预测 `price_hat` 加历史价格残差块，目标日实价只用于结算 |
| 负荷/光伏实际 | 附件 2（Q3 沿用） | `SourceData.load/pv` |
| 光伏预报 | 附件 3（Q3 沿用） | `PVForecast` 线性插值 |
| 负荷预测+残差 | Q2_yy（Q3 沿用） | `SourceData.load_hat` + 历史残差块 |
| 模型/参数 | Q3 骨架与 Q4 扩展 | `q4_price_core.solve_window`，M=30,α=0.9,β=0.2,κ₂=0.5317 |
| 导出链 | Q3（validate/prepare/build） | 模板换 result4-3.xlsx，按验证后的最低实际费用自动选择策略 |

## 主要结果（2025-02-01 ~ 2025-12-31，334 天）

| 策略 | 固定电价总费用/元 | 波动电价总费用/元 | 差/元 |
|---|---:|---:|---:|
| S0（仅 0:00） | 14,861,386 | 15,746,006 | +884,620 |
| S6 | 14,686,100 | 15,511,017 | +824,918 |
| S12 | 14,655,736 | 15,526,461 | +870,725 |
| S18 | 14,875,908 | 15,753,029 | +877,122 |
| S6_12 | 14,517,697 | 15,358,038 | +840,341 |
| **Sall（波动最优）** | **14,517,640** | **15,355,291** | **+837,650** |

**关键结论**：
1. 在不预知目标日实价的因果口径下，波动电价使各策略全年费用较固定价对照高约 84 万至 88 万元。
2. 全部日内更新的价值为 390,715 元，即 S0 与 Sall 的费用差。这个数同时包含光伏预报更新和实时价格不确定性下的重新决策，不能归因于某一个价格时点。
3. **Sall 为波动电价下最低费用策略**，比 S6_12 低 2747 元。差异不足 0.02%，论文应将二者视为非常接近，并以 Sall 作为正式导出方案。
4. `result4-3.xlsx` 已由经独立校验的 Sall 轨迹生成。
