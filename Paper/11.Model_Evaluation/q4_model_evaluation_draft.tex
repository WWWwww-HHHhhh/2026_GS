\section{模型评价}

\subsection{模型的优点}
\begin{itemize}[label=$\checkmark$]
  \item 问题四第二问沿用统一的功率平衡和储能状态约束，将波动电价与负荷、光伏预测误差共同纳入两阶段随机规划。期望费用与条件风险价值相结合，使模型能够同时比较实际购电费用和高费用情形下的风险，而非仅追求某一组场景中的最低费用。

  \item 价格、负荷与光伏场景按同一历史日期抽取残差块，保留日内误差的连续性及变量之间的相关性。模型使用题目指定的光伏预报作为正式输入，并通过受控对照区分价格信息与光伏预报来源的影响，便于解释结果差异。

  \item 问题四第三问在已执行时段不再变动的条件下，利用日内新发布的光伏预报滚动调整剩余时段的购电计划。全年回测表明，增加六点和十二点更新能够降低实际结算费用，十八点更新的边际收益则较小，为选择更新时点提供了依据。
\end{itemize}

\subsection{模型缺点及改进}
\begin{itemize}[label=\textbullet]
  \item 联合场景由近期历史残差抽样生成，对历史样本中未出现的极端价格或供需波动刻画不足。后续可在历史场景之外加入有明确幅度依据的压力场景，并检验购电费用和紧急购电量在极端条件下的变化。

  \item 问题四第三问的未来价格预测在零点确定，日内已经实现的价格只用于结算，没有用于修正尚未执行时段的价格预测。若交易时能够获得连续价格信息，可建立只使用当前及过去观测值的日内价格更新模型，并重新比较滚动调整收益。

  \item 当前按预设时点重新求解，新的预报不一定产生足以抵消计划调整费用的收益。可在每个允许更新的时点，依据当时可获得的信息比较维持原计划与重新优化的场景费用，再决定是否调整。若实际市场另收固定交易手续费，应在取得真实费率后纳入判断，不能将其视为题目已给出的费用。

  \item 模型允许已付费的计划购电量不被全部提取，这与实际交易合同的执行条款有关。推广应用前需确认外网是否允许该类计划削减。若要求全额提取，应据此重新定义执行与结算约束，不能直接沿用当前费用结果。
\end{itemize}
