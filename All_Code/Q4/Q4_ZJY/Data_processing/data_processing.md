# Q4-3 数据处理说明：附件 4 波动电价 → price 矩阵

## 输入

`Data/附件/附件4.xlsx`（Sheet1，365 行 × 145 列）：
- 第 1 列：日期（2025-01-01 ~ 2025-12-31，365 天）
- 第 2~145 列：144 个 10 分钟时段电价（元/kWh），表头为右端点标签（00:10 … 0:00+1，最后一列是字符串 `0:00+1`）

## 处理流程（`Model_Establishment+Solution/q4_data.py`）

1. 按位置取列 `iloc[:, 1:145]`（跳过表头解析，避免 `0:00+1` 字符串干扰），转置为 `price[t, day]`，shape `(144, 365)`。
2. **日期对齐**：附件 4 第 day+1 行对应 `day`（2025-01-01=day0、2025-02-01=day31、2025-12-31=day364），与 Q3 的 `SourceData.dates` 一致。
3. **时间口径**：时段标签为**右端点**（`00:10` = 0:00–0:10 这个时段），与附件 1/2/3 一致，Q3 模型直接可用。

## 校验（`load_q4_price()` 内置断言）

- shape == (144, 365)；0 缺失、全部有限、全部 > 0（结算要求正电价）
- 逐日比对：`price[:,0]=2025-01-01`、`price[:,31]=2025-02-01`、`price[:,364]=2025-12-31`（无错位）
- 统计：范围 [0.0076, 1.7936] 元/kWh，均值 0.7662（与附件 1 完全一致），日内极差均值 1.11

## 产物

- `q4_price_matrix.npy`：上述 (144,365) 电价矩阵的 numpy 缓存（便于快速加载，可经 `load_q4_price()` 重新生成）。
- 该矩阵在 `run_q4.py` 中作为实际结算价格，并在 `q4_price_core.py` 中与因果 `price_hat` 共同构造历史残差场景。

## 信息假设

题面没有说明未来 144 个价格会在每天 0:00 发布。因此，附件4目标日数据不进入当日优化，仅在时段结束后用于实际结算。优化使用 Q4-2 的因果价格预测 `price_hat`，以及严格早于目标日的附件4预测残差块。
