## 1. 时间与索引（不可变）

| 对象 | 规则 |
| --- | --- |
| 附件时刻 τ | 物理区间 `(τ−10min, τ]`（右端点）：`1:00 → 0:50-1:00`，`0:00+1 → 23:50-24:00` |
| 自然日 d | `0:00-24:00`，共 **144** 个十分钟区间；**不得扩成 145** |
| 零基索引 | `x[0] → 0:00-0:10`；`x[60] → 10:00-10:10`；`x[143] → 23:50-24:00` |
| 论文指定时段 | `10:00-10:10 → 60`、`12:00-12:10 → 72`、`14:00-14:10 → 84`、`16:00-16:10 → 96`、`18:00-18:10 → 108`、`20:00-20:10 → 120`（**不许整体减一**） |

## 2. Q4-2 的费用与总量口径

- 自然日计划购电量 `X_d = Σ_{t=0}^{143} x_{d,t}`（含 `x[0]`，即使模板不显示它）。
- 自然日计划购电费 `C_d^plan = Σ_{t=0}^{143} λ_{d,t} · x_{d,t}`。
  **在 Q4-2 中 λ 是当日实现的波动电价（附件4）** —— 这正是 spec §7.3 的既有验证式
  `daily_cost_col == Σ(price * plan_x)`，也就是说 **结算口径 = R1（按交易时刻实际电价结算）**，
  与 Q2 已定稿实现一致，无需另立第二套口径。R2（按 0:00 日前报价结算）只作为稳健性对照保留。
- 每日 `0:00` 只解一次 `x_d[0:144]`；不得用当天未来实际值。

## 3. result4-2.xlsx 的跨行导出（与 result2 完全同构）

计划购电量工作表，令行日期为 d：

```
行 d 前 143 个计划格  ← x_d[1:144]      （标签 0:10-0:20 … 23:50-0:00+1）
行 d 最后一个计划格   ← x_{d+1}[0]      （标签 0:00-0:10+1）
最后一行(2025-12-31)最后计划格 ← 空，且【只有】这一格为空
```

- 报告期首日 2025-02-01 的 `x[0]` 不显示在任何行，但仍参与当日模型、执行、全天量、费用、SOC 与平衡。
- **不得**为了"行内 144 格之和 = 全天购电量"而改成同行直填（会破坏右端点对应关系）。
- 储能/ SOC / 紧急购电**不做**跨行移位，一律按自然日物理区间输出。

## 5. Q4-2 必须复现的因果链

1. 预测：决策日 i 只能用 ≤ i−1 的数据（价格、负荷同一约束；光伏另有 0:00 发布预报可用，属决策时点已得信息）。
2. 场景：只抽**严格早于 i**的最近 30 个已结束日的联合残差块；价格—负荷—光伏**同一历史日**同抽，保持相依结构。
3. 参数（M、β、α、κ、预测超参）：只许在 **2025-01-15 ~ 01-31** 标定；**2025-02-01 ~ 12-31 只报告**。
4. 结算：滚动执行真实的 `x/c/r`，SOC 逐日真实传递；结算时才读当天实际值。
5. 每个计划须可重建：`decision_date / information_cutoff / 预测训练最大日期 / 残差块最大日期 / 参数封存日期`，且满足
   `forecast max date < decision date`、`residual block max date < decision date`。
