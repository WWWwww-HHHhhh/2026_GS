## 一、题目拆解（Q4 原文，逐句）

> 问题 4 实际上，外网的电价也是实时波动的。请针对波动电价，建立微网当天购电策略的数学模型。
> 根据附件2 中的小区负载和光伏发电、附件3 中的光伏发电预报和附件4 中的电价数据，在波动电价下重新计算问题 2 和问题 3。
> 请在论文中给出相应的计算结果，并将完整购电策略分别保存到文件 result4-2.xlsx（对应于问题 2）和 result4-3.xlsx（对应于问题 3）中。

拆成四件事：

1. **变量升级**：唯一被替换的输入是电价 —— 从"每天相同、0:00 已知"（附件1）换成"逐日逐时段波动、决策时未知"（附件4）。负荷、光伏、储能、模板结构全部不动。
2. **Q4-2 = Q2 的物理与结算规则**：一天只做一次 0:00 决策；供能不足时按"交易时刻电价的 **5 倍**"紧急购电；除紧急购电外，费用按**计划购电量**计价。
3. **Q4-3 = Q3 的物理与结算规则**：0:00 定计划量；6:00/12:00/18:00 依据新预报定调整量；调整 < 计划的部分按 **0.5 倍**电价（违约），调整 > 计划的部分按 **1.5 倍**电价；总费用 = 计划购电费 + 紧急购电费 + 调整相关费用。
4. **交付物**：`result4-2.xlsx`、`result4-3.xlsx` 全量填满 + 论文里的计算结果（本次 Q4 未指定日期表，因此论文表格用"全年汇总 + 代表日/代表时段"自建）。

**本质判断**：Q4 不是"把 Q2/Q3 的数字换个电价重跑"，而是**从确定性优化升级为不确定性优化**。题目原文一字未提"预测""场景""风险"，但"电价实时波动"这六个字在信息结构上强制了三件事：① 0:00 决策时电价未知 → 需要价格预测或价格分布；② 目标函数必须对未知价格取期望/风险度量，否则无定义；③ 储能的价值从"固定峰谷差套利"变成"实时价差套利 + 紧急购电保险"，其最优轨迹对价格路径高度敏感。**这三件事就是 Q4 相对 Q2/Q3 的创新增量与得分点。**

## 五、共用数学骨架（Q4-2 / Q4-3 的物理层完全相同）

记号：天 i，时段 t = 1..144，场景 ω，Δ = 1/6 h。

**参数**：L(i,t) 负载电量(kWh)、PV(i,t) 光伏电量(kWh)、λ(i,t) 实时电价(元/kWh)、η = 0.9、E⁰ = 6000、E ∈ [1200, 10800]、C^max = R^max = 833.333 kWh/时段。

**变量**：计划购电量 x(i,t) ≥ 0；实际提取量 y(i,t,ω) ≥ 0；紧急购电量 e(i,t,ω) ≥ 0；充电 c、放电 r ≥ 0；光伏利用 g ≥ 0；弃光 s ≥ 0；储电量 E(i,t,ω)。

**约束**：
- 电量平衡：`y + e + g + r = L + c`（每时段、每场景）
- 光伏拆分：`g + s = PV`，`g ≤ PV`
- 提取上限：`y ≤ x`（计划是上限不是义务 —— 核心结构性约束）
- 储能：`E_t = E_{t-1} + η·c_t − r_t/η`，`E ∈ [1200, 10800]`，`c, r ≤ 833.333`
- 跨日链：`E(i,0) = E(i-1,144)`，起点 6000 kWh，终点软约束
- 非负性

**成本**（按 R1）：
- 计划购电费 `Σ_t λ(i,t)·x(i,t)`（**无论是否提取都要付**）
- 紧急购电费 `Σ_t 5·λ(i,t)·e(i,t,ω)`
- 弃光惩罚（可选，用于打破退化）/ 终端 SOC 惩罚 `κ·|E(T) − E⁰|`

**关键经济量**：储能的影子价格 μ(i,t) = 储能电量的边际价值；套利的必要条件 `μ` 出现峰谷结构，即低 λ 时段充电、高 λ 时段放电。年内套利上限的粗估：可用能量 9600 kWh × 往返效率 0.81 × 日内价差 ≈ 1.0 元/kWh ≈ 7800 元/天上界。相对 Q2 年计划购电费约 1389 万元，量级约 2~3%，**是"波动电价"带来的主要增量收益来源**（论文应给出这个量级判断与分解）。

## 六、Q4-2：波动电价下的日前两阶段随机规划

**决策时序**：0:00 一次性决定全天 x(i,·) 与储能充放电计划；此后不再调整。

**优化问题**：

```
min  (1−β)·E_ω[C(i,ω)] + β·CVaR_α(C(i,ω)) + κ·终端惩罚
s.t. 第一阶段（与场景无关）：x, c, r, E
     第二阶段（逐场景可得）：y^ω, e^ω, g^ω, s^ω + 平衡/上限/储能约束
     C(i,ω) = Σ_t λ^ω·x + Σ_t 5λ^ω·e^ω + 弃光惩罚
```

**三个必须做实的模块**：

1. **因果预测器**（价格、负荷、光伏三路）：价格是最难的一路。建议"日内形状模板 + 日级水平"两段式：形状用同一季节/同星期的历史均价归一曲线，水平用最近 k 日与气温无关的稳健统计（滚动中位数 + 偏差修正）；负荷用"同类型日 + 近期残差修正"；光伏用附件3 的 24 h 预报（Q4-2 只允许用 0:00 发布的那一版）。评价指标：WAPE / MAE，且必须与朴素基线（"用昨日当今日"）对比，逐月报告。
2. **价格—负荷—光伏联合场景**：不允许三个变量独立抽样。做法：取决策日前最近 M₀ 个已结束日，按 144 时段构造三元残差块（相对预测的乘性/加性残差），整块重采样（保留日内时序自相关与跨变量相依），得到 ω = 1..M 场景。M ∈ {10, 20, 30} 做稳定性检验。
3. **风险参数标定**：β、α 只在 2025-01-15~01-31 标定，给出"期望成本 — CVaR"前沿，取拐点；报告期只报告不调参。

**Q4-2 的交付答案**：全年 334 天 × 144 时段的计划购电量、充放电量、紧急购电时段与量、0:00/24:00 储电量、每天汇总购电量与购电费。

## 七、【已移交·仅保留接口说明】Q4-3：波动电价下的滚动 MPC（含预报更新）

**决策时序**：每天 4 个决策点 —— 0:00（计划量）→ 6:00 / 12:00 / 18:00（调整量），每个决策点可用信息 = 该时刻之前已实现的量 + 该时刻发布的 24 h 光伏预报（附件3 对应 issue_hour 的 fh_01..fh_24，小时级）。

**价格处理**：0:00 用日前价格预测；6:00/12:00/18:00 用"已实现价格 + 剩余时段因果预测"（提前量越短越准 —— 这正好呼应"是否需要引入其他时刻预报"的分析需求）。

**费用结构**（题面明确规定）：
```
总费用 = Σ λ_t·x_t                      （计划购电费）
       + Σ 5·λ_t·e_t                    （紧急购电费）
       + Σ 0.5·λ_t·max(x_t − x'_t, 0)   （计划高于调整的违约金）
       + Σ 1.5·λ_t·max(x'_t − x_t, 0)   （调整高于计划的加价）
```
其中 x'_t 为最终调整后购电量。（若采 R2 口径，则计划项按日前报价，需在论文中说明。）

**三个必须做实的模块**：
1. **预报降尺度**：小时级 kW → 10 min 电量，规则显式、只用已知信息、附误差审计（`forecast_conversion_audit`）。
2. **按发布时刻与提前量分类的残差库**：1 h 前预测误差与 24 h 前误差量级不同，不能混用；18:00 的更新只能覆盖次日 0:00 之前的剩余时段（跨日时点要注意）。
3. **软终端 SOC + 真实 SOC 滚动传递**：每次更新后真实执行到下一决策点，SOC 按真实执行推进，不允许用计划 SOC 覆盖。

**必做分析（题目明确要求）**：是否需要引入其他时刻的预报？用 5 组消融回答 —— `S0`（只用 0:00）、`S6`、`S12`、`S18`、`Sall`，比较全年实际总费用、紧急购电率、调整费用、弃光率与单次更新的边际节省，给出"加哪个时点最值"的结论。
