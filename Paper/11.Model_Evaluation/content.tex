\section{模型评价}
\subsection{模型的优点}
\begin{itemize}[label=$\checkmark$]
    \item 采用两阶段优化，在保证最低购电费用的基础上减少冗余充放电，使储能调度方案更加合理。    
    
    \item 将严格因果预测、联合场景生成与 CVaR 随机规划相结合，在避免未来信息泄露的同时兼顾购电经济性与预测偏差风险.
    
    \item 利用日内多时点光伏预报滚动更新购电策略，使模型能够及时修正日前预测偏差，减少高价紧急购电，提高实际运行中的经济性。
\end{itemize}

\subsection{模型缺点及改进}

\begin{itemize}[label=\textbullet]
    \item 模型将负荷和光伏预测值视为完全已知，未考虑实际运行中的预测误差。
    
    \hspace{1em}$\rightarrow$ 可进一步引入预测误差场景，建立随机优化模型，提高调度方案对不确定性的适应能力。

    \item 联合场景主要由近期历史残差抽样生成，对历史数据中未出现的极端波动刻画有限。
    
    \hspace{1em}$\rightarrow$ 可引入极端扰动场景或分布鲁棒优化，提高模型对异常供需波动的适应能力。

    \item 模型在各预报发布时刻均重新优化，但预报更新并非始终能够带来经济收益，频繁调整可能产生不必要的调整成本。
    
    \hspace{1em}$\rightarrow$ 可根据预报精度与预期节省费用设置动态更新机制，仅在调整收益超过成本时重新优化购电计划。
  \end{itemize}
